# Blog-AprendizajePorRefuerzo
Repositorio que forma parte de la serie de blog que estoy realizando sobre aprendizaje por refuerzo.
Si deseas más información, por favor [ingresa](https://migsilva.com/es/).

## Cómo ejecutarlo
Las versiones probadas están en `requirements.txt` y necesitan Python 3.12 o más nuevo:

```
pip install -r requirements.txt
jupyter notebook
```
